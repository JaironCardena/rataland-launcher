Conectar con GitHub

Para publicar, el panel necesita una llave de GitHub que solo sirve para el repositorio rataland-launcher. Se guarda en este navegador y no se envía a ningún otro sitio.

  1. Abre Crear llave en GitHub.
  2. En Repository access elige Only select repositories y marca rataland-launcher.
  3. En Permissions, pon Contents en Read and write.
  4. Pulsa Generate token y pega la llave aquí.
